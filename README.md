# YouTube Cinema

A Chrome extension that gives YouTube a cinema-style experience with ad blocking, clean UI enhancements, and one-click video downloads.

## Features

- Ad blocking on YouTube pages
- Cleaner video page layout and cinema mode
- Download button for quick video downloads
- Native host support for improved download handling

## Installation

1. Open Chrome and go to `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked** and select this repository folder.
4. Open YouTube and enjoy cinema mode.
